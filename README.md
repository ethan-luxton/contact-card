# Work contact card

A lightweight, mobile-first digital business card built with plain HTML, CSS, and JavaScript.

## Preview locally

```sh
python3 -m http.server 8080
```

Then open `http://localhost:8080`.

## Deploy to Netlify

Drag this folder into Netlify Drop, or connect the repository in Netlify. No build command is required; the publish directory is `.`.

## Customize

Replace the placeholder identity and links in `index.html` and `app.js`, then replace `assets/avery-morgan.svg` with a real profile photo.
